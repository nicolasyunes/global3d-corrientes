# Ideas Implementation Plan

> Ejecutado inline en la misma sesión (el usuario pidió "programá"); el
> código vive en los commits de cada tarea.

**Goal:** Sección "Ideas" del panel: juntar links, fotos y archivos 3D de
cosas para imprimir, por colección temática, con galería y tablero.

**Architecture:** Tres tablas (`idea_collections`, `ideas`, `idea_files`) +
depósito `idea-files` + función `link-preview` (Deno) que lee Open Graph.
Frontend en `src/features/ideas/`: lógica pura en `ideas.ts` (probada),
acceso a datos en `ideas.api.ts`, pantallas en `IdeasPage`, `IdeaModal`,
`IdeaDrawer`.

**Tech Stack:** Vite + React 18 + TS, Supabase (Postgres, Storage, Edge
Functions), Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-09-30-ideas-design.md`

## Global Constraints

- Textos en castellano rioplatense (voseo).
- Estados: `idea` | `to_test` | `tested` → "Idea" / "Para probar" / "Probada".
- Prioridad: `normal` | `high` → "Normal" / "Alta".
- Archivos: máx. 50 MB; imágenes, video (mp4/webm/mov), `.stl` `.3mf` `.obj` `.step`.
- RLS: `to authenticated using (true) with check (true)`, como `order_images`.
- No se aplica nada en producción sin permiso.

### Task 1: Migración y tipos
- Create: `supabase/migrations/20261002100000_ideas.sql` (tablas, índices,
  trigger `set_updated_at`, RLS, bucket `idea-files` con límite 50 MB y
  políticas de storage).
- Modify: `src/lib/database.types.ts` (tablas nuevas).

### Task 2: Lógica pura (`src/features/ideas/ideas.ts` + test)
Produce:
- `type IdeaSource`, `detectSource(url: string | null): IdeaSource`,
  `SOURCE_LABEL: Record<IdeaSource, string>`.
- `type IdeaStatus`, `STATUS_LABEL`, `STATUSES`.
- `fileKind(name: string, type: string): 'image' | 'video' | 'model' | null`,
  `validateIdeaFile(file: File): string | null`.
- `collectionCountdown(target: string | null, today: string): string | null`
  ("faltan 18 días", "es hoy", "pasó").
- `filterIdeas(ideas, { collection, onlyHigh, query })`,
  `groupByCollection(ideas, collections)` → secciones en orden, "Sin
  colección" al final.
- `coverOf(idea): { url: string | null; video: boolean }`.
Tests: detección de cada sitio y `other`; validación de tipo/tamaño;
countdown; filtro por colección / "none" / alta / búsqueda; agrupado.

### Task 3: Datos (`src/features/ideas/ideas.api.ts`)
Produce: `listIdeas()`, `listCollections()`, `createIdea(input)`,
`updateIdea(id, patch)`, `deleteIdea(idea)`, `uploadIdeaFile(ideaId, file)`,
`deleteIdeaFile(file)`, `ideaFileUrl(path)`, `createCollection`,
`updateCollection`, `deleteCollection`, `readLink(url)` (invoca
`link-preview`, nunca tira error: devuelve campos vacíos).

### Task 4: Función `supabase/functions/link-preview/index.ts`
Valida http(s), bloquea hosts internos, timeout 6 s, lee ≤1 MB, extrae
`og:title` / `og:image` / `og:site_name` / autor; CORS para el panel.

### Task 5: Ventana "Agregar idea" (`IdeaModal.tsx` + test)
Link con lectura (debounce), recuadro "Leído del link", zona de archivos
(arrastrar / elegir / Ctrl+V), nombre, colección, prioridad; guarda y sube.
Tests: pegar link completa el nombre; sin nombre no guarda; guarda con
colección preelegida.

### Task 6: Detalle (`IdeaDrawer.tsx`)
Editar campos, estado, fotos grandes, archivos 3D con descarga, sumar y
borrar archivos, borrar idea con confirmación.

### Task 7: Pantalla (`IdeasPage.tsx`, `ideas.css`) + ruta + menú
Encabezado, chips de colección con alta/edición, buscador, "Solo alta",
Galería por colección con "Agregar acá", Tablero de 3 columnas con
"Pasar a…" y "+ N más". Ruta `/admin/ideas`; menú lateral debajo de Taller
con contador; en el celular va en "Más".
Tests: render de galería agrupada y filtro por chip.
